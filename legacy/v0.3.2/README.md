# RockwellTowards v0.3.2

RockwellTowards 是一个面向 Microsoft Edge / Chromium 的本地浏览器扩展，用于提取当前 AI 网页对话并导出为 DOCX、PDF 或 Markdown。

## 支持平台

1. ChatGPT：`chatgpt.com`
2. Claude：`claude.ai`
3. Gemini：`gemini.google.com`
4. DeepSeek：`chat.deepseek.com`
5. 智谱清言：`chatglm.cn`

智谱清言当前官方网页入口为 `chatglm.cn`。本版本不支持智谱开放平台控制台中的其他聊天页面。

## v0.3.2 新增

- 捕获用户上传的文件卡片和 AI 回复中的附件卡片。
- 保存附件名称、文件大小、MIME 类型和页面提供的下载/查看链接。
- 捕获用户上传图片与 AI 生成图片，包括只有图片、没有文字的消息。
- DOCX 优先嵌入图片本体；无法取得图片数据时保留图片说明和原图链接。
- PDF 打印页直接排版图片与附件卡片，并等待图片加载后再打开打印窗口。
- Markdown 输出图片语法和附件链接。
- 新增智谱清言 / GLM 提取器。
- 改进 ChatGPT、Gemini、DeepSeek 和 GLM 的模型标签识别。
- 能识别没有平台前缀的标签，例如 `5.6 Sol`、`3.1 Pro`，并规范化为 `ChatGPT 5.6 Sol`、`Gemini 3.1 Pro`。
- 如果同一对话中检测到多个模型，会在文档信息页合并显示；单条消息能找到局部模型标签时，会优先显示该标签。
- 兼容性检查增加图片数、附件数与模型识别结果，但不会记录聊天正文。

## 安装到 Microsoft Edge

1. 下载并完整解压 `RockwellTowards-Edge-Install-v0.3.2.zip`。
2. 打开解压后的 `RockwellTowards-Edge-Load-This-Folder-v0.3.2` 文件夹。
3. 确认第一层直接包含 `manifest.json`、`content.js`、`popup.html` 等文件。
4. 在 Edge 地址栏打开 `edge://extensions/`。
5. 开启“开发人员模式”。
6. 移除或停用旧版 RockwellTowards。
7. 点击“加载解压缩的扩展”，选择上述整个文件夹。
8. 打开一个具体 AI 对话并点击扩展图标。

由于 v0.3.2 新增智谱清言和常用图片托管域名权限，Edge 更新时可能要求重新确认权限。这些权限仅用于读取当前对话和在导出时取得其中的图片；扩展没有服务器，也不会上传聊天正文。

## 使用

- 保持“读取整段长对话”开启：自动滚动并尽量加载完整上下文。
- 关闭该选项：只读取网页当前已经加载的消息。
- 捕获期间可以点击“立即停止”，已读取部分仍可导出。
- 捕获完成后留在扩展弹窗，可直接选择 DOCX 或 PDF。
- “高级预览与筛选”用于删减消息、修改标题、选择排版和分卷。

## 文件与图片的准确含义

### 图片

RockwellTowards 会尝试取得图片像素并嵌入 DOCX/PDF。下列情况可能只能保留说明或链接：

- 图片链接已经失效；
- 网站使用了扩展无法读取的临时 Blob；
- 图片服务器拒绝跨域访问；
- 图片过大或格式无法转换；
- 捕获时图片尚未加载完成。

### 文件

DOCX 本身不会把网页附件的任意二进制文件嵌入为可双击打开的 Word 内嵌对象。本版本保存的是：

- 文件名；
- 大小；
- 类型；
- 网页提供的可用链接。

如果附件链接带登录状态或短期签名，日后可能失效。RockwellTowards 也无法从网页中恢复平台没有展示的附件正文。

## 模型识别限制

模型标签来自网页当前实际展示的按钮、无障碍标签、消息局部标识或页面状态字段。若平台只显示产品名、不显示精确模型版本，RockwellTowards 会诚实地退回 `ChatGPT`、`Gemini`、`DeepSeek` 或 `智谱清言`，不会根据营销页面猜测具体模型。

## 开发

要求 Node.js 20 或更高版本。

```bash
npm ci
npm test
npm run build
```

构建结果位于 `dist/`。

## 已知边界

- 无法读取隐藏系统提示词、内部推理、已删除消息或服务器端未加载数据。
- 只捕获当前打开的对话分支。
- AI 网站会不定期改版；出现漏抓时可在“高级工具”中运行兼容性检查。
